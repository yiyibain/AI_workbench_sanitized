# AI Workbench — 智能策略规划平台

面向企业管理层的 AI 决策辅助工具，覆盖业务诊断、策略制定、指标规划与激励设置全流程。

## 核心特性

- **AI 业务大脑**：内置行业运营体系与产品矩阵知识库，所有 AI 建议均基于业务逻辑生成，而非通用回答
- **实时 AI Copilot**：贯穿全流程的智能助手，实时提供诊断分析、风险预警和优化建议
- **模块化架构**：各功能模块独立可配置，可按需接入实际业务数据源

## 功能模块

### 1. 公司体检报告

#### 产品表现诊断
- **就数论数**：提取内外部数据，定位变化幅度较大的产品及指标，提供风险预警
- **数据解读**：联网获取相关信息，从多维视角分析产品表现的可能原因，并给出进一步定位问题的建议

#### 省份间横向对比
- 基于市场份额、ROI、准入率、渗透率等核心维度，AI 智能定位各省份表现差异
- 生成省份"健康度评分"，结合数据总结潜在原因

### 2. 策略制定

#### 生意大盘观测
- **切分维度定义**：AI 输出适合该产品商业特性的市场观测维度
- **Mekko 数据看板**：依照维度生成看板，帮助定位未布局或份额偏低、具备提升潜力的细分市场

#### 机会点甄别与提炼
- AI 总结在细分市场中存在缺口的原因维度
- 基于数据分析，输出"为何当前未赢得该市场"的原因及策略方向

#### 策略共创
- AI 针对发现的机会点生成初版策略建议
- 支持用户在 AI 建议基础上迭代修改或输入新想法
- 拖拽调整策略优先级，确保策略可落地

### 3. 指标规划（即将推出）

设定和追踪关键业务指标，确保策略落地执行

### 4. 奖金设置（即将推出）

基于指标完成情况，智能计算和分配激励

## 快速开始

### 安装依赖

```bash
npm install
```

### 配置环境变量

复制 `.env.example` 为 `.env`，并填入你的 API Key：

```bash
cp .env.example .env
```

在 `.env` 中填入：

```
VITE_DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

> 如果没有 API Key，应用会使用模拟数据运行，AI 分析功能会返回预设的示例结果。

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173` 启动。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。
